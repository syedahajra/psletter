# Academic Statement Generator

A web application that generates customized academic documents such as recommendation letters, research statements, teaching statements, personal statements, and more.

## Features

* Generate professional academic documents with customizable inputs.
* Supports:

  * Recommendation Letters
  * Research Statements
  * Teaching Statements
  * Personal Statements
* User-friendly, responsive web interface.

## Technology Stack

* **Backend:** Python Flask
* **Frontend:** HTML, CSS, Bootstrap

## Usage

1. Clone the repository:

   ```
   git clone https://github.com/syedahajra/psletter.git
   ```

2. Install dependencies:

   ```
   pip install -r requirements.txt
   ```

3. Run the Flask app:
   before running update api key with your key
   ```
   python app.py
   ```


4. Open your browser and go to `http://localhost:5000`.

5. Fill out the form and generate your academic statement.
